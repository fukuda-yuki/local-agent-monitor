## Common safety gate

`preflight.ps1` is Windows-only and performs no creation or cleanup. Before any later wrapper may act, the operator must provide two separate owner-marked directories under the system temporary root. Each contains only the closed JSON `.cao-issue-158-owner.json`, cross-binding the process-local run id, candidate, kind, and SHA-256 hashes of both physically canonical runtime/result paths. Every existing component and reparse target is resolved before containment, alias, and repository-overlap checks. The normalized lexical and resolved physical root paths must be identical, and the owner marker must be a regular file at its exact physical leaf with no link identity, including hard links, symbolic links, junctions, or reparse points.

`scan-leaks.ps1` accepts only a passed, closed-schema Windows or Linux JSON result. Before acceptance it re-proves the same detached clean candidate, canonically resolves the absent runtime leaf through its existing physical parent, verifies that the surviving result owner cross-binds that exact runtime identity, and permits only the owner plus declared JSON. Its bounded decoder applies the same prohibited-content rules to raw, URL, base64, hex, UTF-8/16/32 text. Neither script prints paths, values, exceptions, marker text, stderr, or file content.

Run `self-test.ps1` to exercise the common gate in a disposable local Git repository. Its helper load, setup, assertions, and final guarded cleanup share one closed boundary; success is emitted only after confirmed fixture absence, while every failure emits only `self_test_result=BLOCKED check=internal`. The self-test owns and removes its fixture and performs no network, SDK, WSL, service, global-setting, or repository mutation.
